# CT-007561 · Descent data versus sheaves under an fppf covering of algebraic spaces: for an fppf covering {X_i -> X} of algebraic spaces over S, descent data relative to the covering are equivalent to sheaves F on (Sch/S)_fppf with a map F -> X such that every X_i x_X F is an algebraic space; F is an algebraic space iff the corresponding datum is effective.
