# CT-004875 · Recovering the tail of a graded module over a general Noetherian graded ring: for A Noetherian graded, d the lcm of degrees of generators over A_0, M a finite graded module, X = Proj(A), k in Z: N' = bigoplus_{n >= k} H^0(X, M(n)^tilde) and N = bigoplus_{n >= k} H^0(X, M^tilde(n)) are finite A-modules, there are canonical maps N -> N' and (k small) M -> N', M_n -> N'_n is an isomorphism for n >> 0, and N_n -> N'_n is an isomorphism whenever d divides n.
