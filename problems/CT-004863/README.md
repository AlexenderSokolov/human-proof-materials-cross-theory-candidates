# CT-004863 · Cohomology of a projective bundle: for S a scheme, E a finite locally free O_S-module of constant rank n + 1 and pi : P(E) -> S, the higher direct images R^q pi_* O_{P(E)}(d) equal Sym^d(E) for q = 0, 0 for q not in {0, n}, and SheafHom(Sym^{-n-1-d}(E) tensor wedge^{n+1} E, O_S) for q = n; the identifications are compatible with base change and isomorphisms of locally free sheaves.
