# CT-004871 · Push-pull for coherent systems under a proper map that is an isomorphism off V(K): for Y Noetherian, J, K quasi-coherent ideal sheaves, f : X -> Y proper and an isomorphism over V = Y \ V(K), I = f^{-1}J O_X, (G_n) in Coh(Y, J), F coherent on X and beta : (f^*G_n) -> F^ an isomorphism in Coh(X, I), there exists alpha : (G_n) -> (f_*F)^ in Coh(Y, J) whose kernel and cokernel are annihilated by a power of K.
